Unit 34: Would you like...? / I'd like... (Polite Offers and Requests)
Would you like a cup of tea?
الترجمة: هل ترغب في كوب من الشاي؟ (طريقة مهذبة لتقديم عرض).
I'd like some information, please.
الترجمة: أود الحصول على بعض المعلومات، من فضلك. (صيغة مهذبة لطلب شيء - اختصار لـ I would like).
Structure Function Example
Would you like + Noun / to-verb Polite Offer / Invitation Would you like to come with us?
I'd like + Noun / to-verb Polite Request (I want...) I'd like to book a table.
Unit 35: Do this! / Don't do that! / Let's do this! (Imperatives and Suggestions)
Come in and sit down.
الترجمة: أدخل واجلس. (صيغة الأمر المباشر باستخدام الفعل مجرداً).
Let's go to the cinema.
الترجمة: دعنا نذهب إلى السينما. (استخدام Let's تقديم اقتراح تشاركي).
Type Structure Example
Positive Imperative Base Verb Open the door.
Negative Imperative Don't + Base Verb Don't touch that!
Suggestion Let's (Let us) + Base Verb Let's have dinner.
Unit 36: I used to... (Past Habits and States)
I used to play tennis, but I stopped.
الترجمة: اعتدت أن ألعب التنس، ولكني توقفت. (عادة سابقة في الماضي لم تعد تحدث الآن).
Where did you use to live before?
الترجمة: أين اعتدت أن تعيش من قبل؟ (صيغة السؤال بـ did ... use to).
Form Structure Example
Positive Subject + used to + Base Verb He used to have long hair.
Negative Subject + didn't use to + Base Verb I didn't use to like coffee.
Question Did + Subject + use to + Base Verb? Did you use to travel a lot?
