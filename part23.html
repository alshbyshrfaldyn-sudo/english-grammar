Unit 67: some and any
I bought some apples, but I didn't buy any oranges.
الترجمة: اشتريت بعض التفاح، لكنني لم أشتر أي برتقال. (استخدام some في الجمل الإيجابية و any في النفي).
Would you like some coffee?
الترجمة: هل ترغب في بعض القهوة؟ (استخدام some في الأسئلة عند العرض أو الطلب).
Word Sentence Type Example
some Affirmative (+) / Offers & Requests (?) I have some money. / Would you like some tea?
any Negative (-) / General Questions (?) I don't have any money. / Have you got any questions?
Unit 68: not + any / no / none
There aren't any cars in the car park.
الترجمة: لا توجد أي سيارات في موقف السيارات. (استخدام not + any مع الفعل المنفي).
How much money do you have? None.
الترجمة: كم من المال لديك؟ لا شيء. (استخدام none للرد القصير بدون ذكر اسم بعدها).
Structure Verb State Example
not + any Negative Verb (-) There isn't any bread.
no + noun Positive Verb (+) There is no bread.
none Standalone (No Noun) How much money? None.
Unit 69: not + anybody/anyone/anything | nobody/no-one/nothing
I don't know anyone in this town.
الترجمة: لا أعرف أحداً في هذه المدينة. (استخدام not + anyone/anybody للنفي مع الأشخاص).
There is nothing in the bag.
الترجمة: لا يوجد شيء في الحقيبة. (استخدام nothing مع فعل إيجابي ليعطي معنى النفي للجماد).
Target not + any... (Negative Verb) no... (Positive Verb)
People not + anybody / anyone nobody / no-one
Things not + anything nothing
Places not + anywhere nowhere
