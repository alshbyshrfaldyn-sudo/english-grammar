Unit 64: go to work / go home / go to the cinema (Use of 'the')
She goes to work by bus every day.
الترجمة: هي تذهب إلى العمل بالحافلة كل يوم. (عدم استخدام the مع كلمات مثل work, bed, school, home عند الحديث عن الغرض الأساسي منها).
Let's go to the cinema this evening.
الترجمة: فلنذهب إلى السينما هذا المساء. (استخدام the دائماً مع cinema, theatre, bank, station).
Category Without "the" With "the"
Institutions / Purpose go to school / work / bed / prison go to the cinema / theatre / bank / station
Home & Transport go home (no 'to' or 'the') go to the airport / the station
Unit 65: this / that / these / those
This picture is nice, but those pictures over there are better.
الترجمة: هذه الصورة جميلة، ولكن تلك الصور هناك أفضل. (مقارنة بين هذا للمفرد القريب هذا وهذه، وتلك للجمع البعيد).
Who is that man standing near the door?
الترجمة: من ذلك الرجل الواقف بالقرب من الباب؟ (استخدام that للمفرد البعيد).
Distance Singular (مفرد) Plural (جمع)
Near (قريب) this (هذا / هذه) these (هؤلاء)
Far (بعيد) that (ذلك / تلك) those (أولئك)
Unit 66: one / ones
Which coat is yours? The blue one.
الترجمة: أي معطف هو لك؟ الأزرق. (استخدام one لتجنب تكرار الاسم المفرد المعدود coat).
Which shoes do you like? The green ones.
الترجمة: أي الأحذية تعجبك؟ الخضراء. (استخدام ones لتجنب تكرار الاسم الجمع shoes).
Number Substituted Pronoun Example
Singular (مفرد) one a big one / the red one / this one
Plural (جمع) ones some new ones / the blue ones / these ones
