Unit 97: Conjunctions (and, but, or, so, because)
I was tired, so I went to bed early.
الترجمة: كنت متعباً، لذا ذهبت إلى النوم مبكراً. (استخدام so للتعبير عن النتيجة).
He stayed home because it was raining.
الترجمة: بقي في المنزل لأنها كانت تمطر. (استخدام because للسبب).
Conjunction Meaning / Function Example
and / but و (إضافة) / لكن (تناقض) I bought an apple and an orange, but I didn't eat them.
or أو (خيارات) Would you like tea or coffee?
so / because لذا (نتيجة) / لأن (سبب) I was hungry, so I ate. / I ate because I was hungry.
Unit 98: Time Clauses (when, before, after, as soon as, until)
I will call you when I arrive.
الترجمة: سأتصل بك عندما أصل. (نستخدم المضارع البسيط بعد روابط الزمن حتى لو كان المعنى مستقبلياً).
Always lock the door before you leave.
الترجمة: اقفل الباب دائماً قبل أن تغادر.
Time Link Rule for Future Time Correct Example
when / as soon as Main Clause (Future) + Link + Present Simple I will write as soon as I have time.
before / after / until Main Clause (Future) + Link + Present Simple Wait until I come back. (NOT until I will come)
Unit 99: Relative Clauses (who, which, that)
The man who lives next door is a doctor.
الترجمة: الرجل الذي يسكن في البيت المجاور هو طبيب. (استخدام who أو that للأشخاص).
Where is the key which was on the table?
الترجمة: أين المفتاح الذي كان على الطاولة؟ (استخدام which أو that للأشياء والحيوانات).
Relative Pronoun Used for Example
who الأشخاص فقط (People) A programmer is a person who writes code.
which الأشياء والحيوانات (Things/Animals) I built an app which helps students.
that الأشخاص والأشياء (Both) The book that I read was amazing.
